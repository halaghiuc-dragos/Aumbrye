# Security policy

## Supported versions

Security fixes are applied on the `main` branch. There are no long-term release branches at this stage of development.

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report security issues privately by opening a [GitHub Security Advisory](https://github.com/halaghiuc-dragos/Aumbrye/security/advisories/new) or by contacting the repository owner through GitHub.

Include:

- A description of the vulnerability and its impact
- Steps to reproduce, with proof-of-concept if available
- Affected components (client, API, web, infrastructure)
- Suggested remediation, if you have one

You should receive an acknowledgment within seven days. We will work with you on a fix and coordinated disclosure timeline.

## Scope

In scope: the Godot client, ASP.NET Core API, React web app, Docker Compose services, and CI workflows in this repository.

Out of scope: third-party dependencies (report upstream), hosted infrastructure not defined in this repo, and social-engineering attacks.
