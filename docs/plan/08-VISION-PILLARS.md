# Vision and Design Pillars

## Vision

Aumbrye is a premium single-player action roguelite RPG.

> Every run should feel handcrafted.

Not an endless procedural sandbox — a game where each run feels like exploring another forgotten kingdom forged in the shadow of Aumbrye.

## Pillars (priority order)

1. **Combat First** — responsive, weighty, readable, difficult, fair; skill > level
2. **Exploration** — secrets, shortcuts, treasure, puzzles, minibosses, lore
3. **Replayability** — procgen serves variety; never the spectacle
4. **Beautiful Simplicity** — few systems, deep interactions

## Gameplay loop

```
Town → Choose Dungeon → Server Generates → Explore → Fight → Loot → Boss → Escape → Upgrade → Repeat
```

## Inspirations (reference only)

- Combat: Dark Souls, Elden Ring
- Replayability: Hades, Dead Cells
- Exploration: Tunic, Hyper Light Drifter
- Loot: Diablo II, Path of Exile
- Pixel art: CrossCode, Octopath, Sea of Stars, Children of Morta

## Success memory test

Players should remember: satisfying combat, memorable bosses, rewarding exploration, exciting loot, handcrafted environments, meaningful progression.

Players should not remember the algorithm.
