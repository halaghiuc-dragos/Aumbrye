## Per-theme deliverable checklist

For each theme, all must be done before marking theme complete:

- [ ] Biome JSON (`content/biomes/{id}.json`)
- [ ] Room template set (≥6 templates)
- [ ] Lighting profile
- [ ] Audio profile (ambience, explore, combat, boss)
- [ ] Enemy pool (4–5)
- [ ] Miniboss
- [ ] Boss (≥2 phases)
- [ ] Puzzle type (≥1)
- [ ] Trap set (≥1)
- [ ] Loot tables + ≥2 unique items
- [ ] Generator rules (secrets, budgets)
- [ ] Smoke: 20 seeds generate + 1 full manual clear
