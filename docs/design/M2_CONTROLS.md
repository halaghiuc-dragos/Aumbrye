# M2 gameplay controls

> **M2 additions only.** Combat bindings remain locked in [M1_CONTROLS.md](M1_CONTROLS.md).  
> These controls apply in hub, dungeon, and inventory UI.

| Action | Binding | Notes |
|--------|---------|-------|
| Interact | **E** | Portals, chests, doors (gamepad **X**) |
| Inventory | **Tab** | Toggle grid inventory (gamepad **LB**) |
| Inventory cursor | **Arrow keys** / **D-pad** | Move selection in grid |
| Equip / confirm | **Enter** / **A** | Equip weapon from inventory |
| Close inventory | **Tab** / **Esc** | |
| Results continue | **Enter** / **A** | After castle run |

## Hub

| Location | Action |
|----------|--------|
| Castle Portal (north) | **E** — start Forgotten Castle run |
| Training Arena door (east) | **E** — load M1 combat arena |
| Combat arena — Return to Hub (west) | **E** — back to hub |

## Locked with M1

Do not change: WASD, mouse look, sprint, dodge, jump, attacks, guard, lock-on, F1/F2/F3 debug. See [M1_CONTROLS.md](M1_CONTROLS.md).
